Актёр — сущность `storyscenes:actor`: безобидный неуязвимый человечек с любым скином. Он ходит по маршруту, поворачивается к точке и машет рукой. Реплики актёров показывают обычные [титры](../developers/).

## Скин и поведение

- Скин — любая текстура **64x64** с обычными руками. Путь указывается как `мод:textures/entity/npc.png`. Если путь пуст, берётся скин Стива.
- Имя показывается над головой, можно включить свечение.
- Актёры не сохраняются в мире и сами исчезают через десять минут.
- У каждого зрителя свой состав актёров. Когда сцена у зрителя заканчивается, его актёры убираются сами.

## Управление из кода

```java
Scene s = StoryScenesAPI.builder()
    .actorSpawn(0, "guide", "mymod:textures/entity/guide.png",
            StoryStages.mark(stage, "hall.p1"), 0f, "Гид", false)
    .actorWalk(40, "guide", 0.8,
            StoryStages.mark(stage, "hall.door"), StoryStages.mark(stage, "hall.exit"))
    .actorLook(100, "guide", new Vec3(10, 65, 10))
    .actorSwing(110, "guide")
    .actorDespawn(160, "guide")
    .viewerTeleport(0, new Vec3(5, 66, 12))
    .build();
```

| Метод | Что делает |
|---|---|
| `actorSpawn(тик, id, скин, позиция, поворот, имя, свечение)` | актёр появляется. Если актёр с таким id уже есть, команда игнорируется |
| `actorWalk(тик, id, скорость, точки...)` | идёт по маршруту; скорость 1.0 соответствует обычному шагу. Новый маршрут заменяет прежний |
| `actorLook(тик, id, точка)` | поворачивается лицом к точке |
| `actorSwing(тик, id)` | взмах руки |
| `actorDespawn(тик, id)` | убрать одного актёра |
| `actorsClear(тик)` | убрать всех актёров зрителя |
| `viewerTeleport(тик, позиция)` | переносит зрителей в точку |

Всё это обычные триггеры с id `storyscenes:actor`, поэтому сцена с актёрами остаётся обычной: её можно зарегистрировать, сохранить, запустить и пропустить.

> [!NOTE] Кто запускает
> Актёры создаются в мире игрока, запустившего сцену, и управляются, пока он на сервере.

## Из датапака или командами

Актёрами можно управлять и в сценах из JSON или созданных командами: нужны триггеры `storyscenes:actor` с аргументом в формате `команда|параметры`, например `spawn|guide|mymod:textures/entity/guide.png|x|y|z|поворот|имя|свечение`. Для кода удобнее методы `SceneBuilder`.
