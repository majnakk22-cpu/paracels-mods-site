Все команды требуют права оператора (уровень 2) и работают из командных блоков.

**Идентификаторы сцен.** Короткое имя (`intro`) или `world:intro` — сцена мира, созданная командами. `namespace:имя` — сцена из мода или датапака. Имя новой сцены: только `a-z`, `0-9`, `_` и `-`, до 48 символов. Время везде в тиках.

## Управление сценами

| Команда | Что делает |
|---|---|
| `/scene new <имя>` | создать пустую сцену |
| `/scene delete <имя>` | удалить сцену мира |
| `/scene list` | показать сцены мира и зарегистрированные |
| `/scene play <id> [игроки]` | запустить (по умолчанию себе) |
| `/scene stop [игроки]` | остановить |
| `/scene view <id>` | показать содержимое любой сцены |
| `/scene copy <id> <имя>` | скопировать сцену мода или датапака в сцену мира, чтобы её править |
| `/scene edit <имя> info` | показать сцену с номерами событий |

## Редактирование

Начало: `/scene edit <имя> ...`

| Окончание команды | Что делает |
|---|---|
| `origin here`, `origin <x y z>`, `origin clear` | начало координат сцены: «~» в `cam at`, `cam lookat` и `run` считается от него |
| `cam add [тик] [fov]` | ключ камеры из позиции и взгляда игрока (без тика добавляет 40 к последнему) |
| `cam at <тик> <x y z> <yaw> <pitch> [fov]` | ключ камеры по координатам (для командных блоков) |
| `cam lookat <тик> <откуда> <куда> [fov]` | ключ камеры «из точки на точку» |
| `cam update <№>`, `cam goto <№>`, `cam remove <№>` | перезаписать ключ, телепортироваться в него, удалить |
| `cam roll <№> <угол>` | крен камеры |
| `cam fov <№> <fov>` | зум (0 означает «как в настройках») |
| `cam mode <№> smooth` или `linear` | плавный сплайн или прямая до следующего ключа |
| `say <тик> <длит> <говорящий> <текст>` | титр. Вместо имени `-` даёт титр без имени |
| `fade <тик> <длит> out` или `in [hex]` | затемнение или проявление; цвет `ffffff` даёт белую вспышку |
| `run <тик> <команда>` | команда сервера от имени запустившего с правами 4 |
| `trigger <тик> <id> [аргумент]` | вызовет `SceneEvent.Trigger` для кода твоего мода |
| `sound <тик> <id> [громкость] [высота]` | звук, в том числе из ресурспака |
| `remove say`, `fade`, `run`, `sound` или `trigger <№>` | удалить событие |
| `length <тики>` | длина сцены (0 означает автоматически) |
| `option bars`, `skippable` или `protect <true/false>` | параметры сцены |

> [!TIP] Имя говорящего
> Если в имени есть пробел, пиши `Старый_маг` или бери имя в кавычки: `"Старый маг"`.

## Origin: сцена, привязанная к месту

Пока у сцены задан `origin`, все координаты в `cam at`, `cam lookat` и команды `run` считаются от него. Достаточно один раз написать `origin here` в начале, и дальше можно писать `~ ~2 ~-10`. Сцену легко пересобрать на новом месте.

## Пример: сцена из командных блоков

Поставь командные блоки в ряд стрелками в одну сторону: первый импульсный, остальные цепные и «всегда активны». В каждый блок вставь по команде по порядку:

```
scene delete example_intro
scene new example_intro
scene edit example_intro origin here
scene edit example_intro cam lookat 0 ~-14 ~8 ~-14 ~ ~2 ~3 70
scene edit example_intro cam lookat 80 ~-6 ~3 ~-4 ~ ~1.6 ~3 60
scene edit example_intro fade 0 30 in
scene edit example_intro say 20 70 - Заброшенная деревня. Здесь давно никого нет...
scene edit example_intro say 90 60 Старик Эй, путник! Ты как раз вовремя.
scene edit example_intro fade 300 30 out
```

Запуск: `scene play example_intro @a[distance=..40]`.

Пропуск сцены — **Backspace** (клавишу можно сменить в настройках управления).

## Команды локаций

| Команда | Что делает |
|---|---|
| `/scene stage list` | список локаций из датапаков |
| `/scene stage build <id>` | построить локацию заново |
| `/scene stage visit <id> [метка]` | построить локацию и телепортироваться к метке |
| `/scene stage fx <id> <эффект> <состояние>` | переключить эффект локации |

Подробнее о локациях: [Локации](../stages/).
