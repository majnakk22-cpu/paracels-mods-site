Локация (stage) — это декорация, которую библиотека строит по описанию из датапака: блоки, именованные эффекты, точки для актёров и готовые планы камеры. Файл лежит в `data/<мод>/story_stages/<имя>.json`, id локации `<мод>:<имя>`.

## Формат файла

```json
{
  "dimension": "mymod:studio",
  "origin": [0, 70, 0],
  "palette": ["minecraft:stone_bricks", "minecraft:redstone_lamp[lit=true]", "minecraft:air"],
  "runs": [[0, 9, 0, 3, 0], [4, 4, 1, 3, 1]],
  "fx": { "lamp": { "on": [[4, 4, 1, 3, 1]], "off": [[4, 4, 1, 3, 2]] } },
  "bounds": [-2, -2, -2, 12, 8, 12],
  "marks": { "hall.door": [5.0, 0.0, 3.5] },
  "cams":  { "hall.A": [5.0, 3.0, 12.0, 5.0, 1.5, 2.0, 70] }
}
```

| Поле | Что значит |
|---|---|
| `dimension` | где строить; без поля берётся обычный мир (overworld) |
| `origin` | мировая точка `[x, y, z]`, от которой считаются все координаты файла |
| `palette` | список блоков с состояниями, например `minecraft:redstone_lamp[lit=true]` |
| `runs` | отрезки блоков вдоль оси x: `[x0, x1, y, z, индекс в палитре]` |
| `fx` | именованные эффекты: для каждого состояния свой набор отрезков (лампы вкл/выкл и т. п.) |
| `bounds` | объём `[x0, y0, z0, x1, y1, z1]`, который очищается перед постройкой |
| `marks` | именованные точки относительно `origin`, нужны актёрам и камере |
| `cams` | готовые планы камеры относительно `origin`: `[x, y, z, цельX, цельY, цельZ, fov]` |

> [!WARNING] Палитра
> Если блок в палитре написан неверно, на его месте будет поставлен камень, а в логе появится предупреждение.

Измерение должно быть загружено на сервере, иначе постройка не выполнится.

## Построить и переключить

Из игры (права 2): `/scene stage build mymod:studio`, `/scene stage fx mymod:studio lamp off`.

Из кода:

```java
ResourceLocation stage = new ResourceLocation("mymod", "studio");

StoryStages.build(stage);                          // очистить объём и поставить блоки заново
Vec3 door = StoryStages.mark(stage, "hall.door");  // мировая позиция метки (или null)
double[] cam = StoryStages.cam(stage, "hall.A");   // {x, y, z, цельX, цельY, цельZ, fov} или null
StoryStages.applyFx(stage, "lamp", "off");
StoryStages.ids();                                 // все найденные локации
```

Вызывай `build` перед запуском сцены.

Из таймлайна сцены локацию строят и переключают методы `stageBuild(тик, локация)` и `stageFx(тик, локация, эффект, состояние)`:

```java
Scene s = StoryScenesAPI.builder()
    .stageBuild(0, stage)
    .stageFx(120, stage, "lamp", "off")
    .build();
```

## Чанки и камера

Чанки грузятся вокруг игрока, а не вокруг камеры. Для больших локаций держи зрителя рядом с камерой: `viewerTeleport(тик, точка)` переносит всех зрителей сцены.
