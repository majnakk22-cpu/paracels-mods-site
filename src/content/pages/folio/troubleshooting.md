Folio — самостоятельный проект Gradle под Minecraft 1.20.1 и Forge 47. Для сборки нужны JDK 17 и Gradle 8.x:

```
gradle build
```

Готовый мод — `build/libs/folio-1.0.0.jar`. Его кладут в папку `mods` рядом с модами, которые от него зависят.

## Подключение к проекту мода

В `mods.toml` вашего мода добавьте зависимость от `folio` (см. [Быстрый старт](../quick-start/)). Сам jar подключается через `fg.deobf`, потому что собранный файл содержит продакшн-имена.

> [!NOTE] Не проверено в живой сборке
> Оба способа ниже описаны по настройкам проекта Folio, но в рабочей сборке не прогонялись.

**Способ 1 — файл в `libs/`**, самый простой. Скопируйте `folio-1.0.0.jar` в `libs/` проекта мода:

```groovy
repositories {
    flatDir {
        dirs 'libs'
        content { includeGroup 'dev.folio' }
    }
}
dependencies {
    implementation fg.deobf("dev.folio:folio:1.0.0")
}
```

**Способ 2 — локальный Maven.** В проекте Folio выполните `gradle publishToMavenLocal`, затем в проекте мода:

```groovy
repositories {
    mavenLocal {
        content { includeGroup 'dev.folio' }
    }
}
dependencies {
    implementation fg.deobf("dev.folio:folio:1.0.0")
}
```

## Версии

Версия 1.0.0 включает экраны книги и журнала, описание и реестры, хранение записей, пакет, разметку, кнопки и скин по умолчанию. Тема `FolioTheme` и прокрутка закладок добавлены без смены номера версии. API обратно совместим: книги без `.theme(...)` выглядят как раньше, а `.skin(...)` работает по-прежнему.

## Частые проблемы

| Что видно | Причина и решение |
|---|---|
| Вместо текста показываются ключи вроде `guide.yourmod.welcome.text` | В lang-файле нет ключа или не совпадает префикс; сверьте с `.langPrefix(...)` и id главы |
| Вместо иконки рисуется книга | Не найден предмет с таким id; проверьте `modid:item_id` |
| Гиперссылка не нажимается | В книге нет главы с таким id; сверьте с `.chapter(...)` |
| Строка перевода выглядит сломанной | В тексте есть символ процента; уберите его |
| Игра падает при запуске с `IllegalStateException` про книгу | В книге нет разделов или глав, либо у главы неверный номер раздела |
| Выделенный сервер падает при открытии книги | `FolioClient` вызван на сервере; открывайте книгу на клиенте через `DistExecutor`, журнал через `FolioJournals.open` |
| Запись не открывается | `FolioJournals.unlock` вернул `false` для неизвестного id журнала или записи; сверьте с регистрацией |
| После переименования журнала пропали записи | Изменился ключ хранения; задайте прежний через `.storageKey(...)` |
| Закладки вылезают за рамку книги | Нужна версия Folio с прокруткой закладок: при девяти и больше закладках колонка листается |
