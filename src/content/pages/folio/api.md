Часть интерфейса работает на сервере, часть только на клиенте, и перепутать их нельзя: клиентские вызовы на сервере упадут. Описания книг и журналов регистрируются в конструкторе мода на обеих сторонах.

| Класс и метод | Где вызывать | Что делает |
|---|---|---|
| `FolioBooks.register(def)` | Конструктор мода, обе стороны | Регистрирует книгу; повторный id заменяет прежнюю |
| `FolioBooks.get(id)` | Любая сторона | Описание книги или `null` |
| `FolioJournals.register(def)` | Конструктор мода, обе стороны | Регистрирует журнал |
| `FolioJournals.definition(id)` | Любая сторона | Описание журнала или `null` |
| `FolioJournals.unlock(player, journalId, entryId)` | Сервер | Открывает запись; `true`, если она новая; показывает уведомление |
| `FolioJournals.has(player, journalId, entryId)` | Сервер | Открыта ли запись |
| `FolioJournals.unlocked(player, journalId)` | Сервер | Список открытых id |
| `FolioJournals.open(player, journalId, entryId)` | Сервер | Отправляет игроку пакет и открывает журнал; `entryId` можно передать `null` |
| `FolioClient.openBook(bookId)` | Только клиент | Открывает экран книги |
| `FolioClient.openJournal(journalId, unlocked, openId)` | Только клиент | Открывает экран журнала; обычно его вызывает сам пакет |

Вызывайте `FolioClient` через `DistExecutor`, как в примере предмета-книги на странице [Быстрый старт](../quick-start/), иначе выделенный сервер попробует загрузить клиентские классы.

## Что где хранится

- Открытые записи журнала лежат в постоянных данных игрока (`Player.PERSISTED_NBT_TAG`) под ключом `storageKey` журнала, поэтому переживают смерть. Ключ по умолчанию собирается как `folio_journal_<namespace>_<path>`. Если вы переименовываете журнал, задайте прежний ключ через `.storageKey(...)`, иначе старые записи пропадут.
- Прогресс чтения книги (прочитанные главы и последнее место) хранится только на клиенте, в памяти, отдельно для каждой книги. После перезапуска игры он сбрасывается.

## Пакет

Folio регистрирует собственный сетевой канал; пакет открытия журнала отправляется только вызовом `FolioJournals.open`. Свою сетевую часть для журнала писать не нужно.
