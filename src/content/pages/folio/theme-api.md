Каждый мод задаёт оформление своей книги сам через `FolioTheme` и передаёт его в `BookDefinition` или `JournalDefinition` методом `.theme(...)`. Всё, что не задано, остаётся как в стандартной теме Folio, поэтому можно менять только нужное, а книги без `.theme(...)` выглядят как раньше.

Тема состоит только из цветов и ссылок на текстуры, клиентских классов она не трогает, так что её можно создавать в конструкторе мода на любой стороне. Цвета — `0xAARRGGBB`; без альфы (`0xRRGGBB`) цвет считается непрозрачным.

```java
FolioTheme theme = FolioTheme.builder()
        .skin(new ResourceLocation("yourmod", "textures/gui/guide_book.png"))
        .title(0xFFC0392B).heading(0xFFC0392B)
        .text(0xFFE6D8D8, 0xFFFFFFFF)
        .link(0xFFFF8A65, 0xFFFFCCBC)
        .arrow(0xFF4A2A2A, 0xFFC0392B, 0xFF241414, 0xFF3A1E1E, 0xFFD9B8B8, 0xFFFFFFFF)
        .tab(0xFF120808, 0xFF1E1010, 0xFF3A1E1E, 0.30F)
        .row(0xFFE6D8D8, 0xFFFFFFFF, 0xFF9A8080, 0xFFC0392B)
        .build();

BookDefinition.builder(BOOK).theme(theme) /* ... */ .build();
JournalDefinition.builder(JOURNAL).theme(theme) /* ... */ .build();
```

Одну тему можно отдать и книге, и журналу. `theme.toBuilder()` возвращает билдер с теми же значениями: так берут базовую тему мода и меняют пару цветов для журнала.

## Фон книги

| Вариант | Как задать |
|---|---|
| Скин по умолчанию | Ничего не задавать |
| Своя текстура | `.skin(texture)` — файл 512×256: разворот 312×196 в левом верхнем углу, эмблема обложки 32×32 в точке (320, 0) |
| Текстура другого размера | `.skin(texture, texW, texH)` — те же пропорции, например 1024×512 для чёткого фона; фон сжимается до размера книги на экране |
| Разворот лежит не в углу | `.skinRegion(u, v, w, h)` |
| Без текстуры | `.panel(рамка, кант, страница, контур страницы, корешок)` — рамка и страницы рисуются заливкой |

Зона текста от фона не зависит: две страницы шириной 132 пикселя, левая от x=18, правая от x=162, обе от y=34. Рисуйте текстуру так, чтобы текст ложился на страницы, а внизу оставалось около 24 пикселей под стрелки листания.

Вращающаяся эмблема на обложке по умолчанию берётся из скина, справа от разворота. Другую текстуру задаёт `.emblem(texture, u, v, size, texW, texH)`, убрать совсем — `.noEmblem()`. При `.panel(...)` эмблемы нет, пока вы не задали свою.

Короткая запись `.skin(texture)` у билдеров книги и журнала работает по-прежнему: она заменяет только текстуру, остальное берётся из темы.

## Цвета текста

| Метод | Что красит |
|---|---|
| `.title(c)` | Название на левой странице |
| `.heading(c)` | Заголовки глав и линия под ними |
| `.text(обычный, жирный)` | Основной текст и выделение |
| `.muted(c)` | Счётчики страниц, подписи |
| `.subtitle(c)` | Подпись на обложке |
| `.link(обычная, при наведении)` | Гиперссылки в тексте, «Назад», «Продолжить чтение» |
| `.note(полоса, текст)` | Врезки-советы |
| `.bullet(c)` | Маркеры списка |
| `.progressBar(заливка, фон, контур)` | Полоска прогресса на обложке |
| `.locked(акцент, недоступный текст)` | Закрытые записи журнала и недоступные текстовые кнопки |

## Кнопки

| Метод | Что настраивает |
|---|---|
| `.arrow(контур, контур при наведении, заливка, заливка при наведении, значок, значок при наведении)` | Стрелки листания и стрелки прокрутки закладок |
| `.arrowDisabled(контур, заливка, значок)` | Недоступная стрелка |
| `.tab(контур, невыбранная, выбранная, доля акцента)` | Закладки; доля акцента (0…1) — сколько цвета раздела подмешать к выбранной |
| `.contentsTab(c)` | Цвет закладки «Оглавление» (в журнале «Все записи») |
| `.row(название, название при наведении, шеврон, метка «прочитано»)` | Строки-ссылки: разделы, главы, записи |
| `.rowDivider(argb)` | Пунктир под строкой; `0` убирает его |
| `.rowHighlight(сила 0–255, акцентная полоска)` | Подсветка строки при наведении |

Акцентный цвет каждого раздела и категории по-прежнему задаётся в данных: в `.section(...)` и `.category(...)`.

## Спрайты вместо заливки

Для стрелок, закладок и строк можно задать текстуру, которая растягивается по девяти частям:

```java
FolioTheme.Sprite arrows = FolioTheme.sprite(texture, u, v, w, h, border, texW, texH);
theme.arrowSprite(arrows).tabSprite(tabs).rowSprite(rows)
```

Состояния лежат в текстуре друг под другом, каждое высотой `h`: на `v` — обычное, на `v + h` — наведение, на `v + 2h` — недоступная (только у стрелок). У закладок «выбрана» рисуется как состояние наведения. `border` — ширина углов, которые не растягиваются. Значки, текст и шевроны рисуются поверх спрайта; если подсветка уже нарисована в нём, отключите программную: `.rowHighlight(0, false)`.
