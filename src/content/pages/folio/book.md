Книгу описывает `BookDefinition`: у неё есть разделы, а в каждом разделе главы. Названия и тексты берутся из lang-файлов по префиксу.

## Методы билдера

| Метод | Что задаёт |
|---|---|
| `BookDefinition.builder(id)` | Идентификатор книги (`ResourceLocation`), по нему книгу открывают |
| `.langPrefix(prefix)` | Префикс ключей глав и разделов, например `guide.yourmod` |
| `.title(key)` | Ключ названия на обложке |
| `.subtitle(key)` | Ключ подписи на обложке |
| `.section(icon, argbColor)` | Новый раздел: id предмета для иконки и цвет акцента; разделы нумеруются с нуля в порядке вызова |
| `.chapter(id, section, icon)` | Глава: короткий id, номер раздела и id предмета для иконки |
| `.theme(theme)` | Фон, цвета, кнопки (см. [FolioTheme](../theme-api/)) |
| `.skin(texture)` | Короткая запись: заменить только текстуру фона |
| `.build()` | Собрать описание; затем его регистрируют в `FolioBooks.register` |

Что стоит знать:

- Иконка — id предмета вида `modid:item_id`. Цвет — `0xAARRGGBB`, он красит закладку раздела, полоску у строк и подсветку.
- Главы показываются в разделе в том порядке, в каком вы вызывали `.chapter(...)`.
- Id главы должен быть уникален в книге: по нему строятся ключи перевода и гиперссылки.
- Разделов может быть сколько угодно. До 8 закладок видны все сразу; когда их больше, колонка закладок показывает окно из семи со стрелками и листается колесом мыши слева от книги.
- Списки показывают по пять строк на странице, поэтому длинные оглавления листаются сами.
- Если книга регистрируется с уже занятым id, действует последняя регистрация.
- `build()` бросает `IllegalStateException`, если в книге нет ни одного раздела или главы либо у главы указан несуществующий номер раздела. Ошибка видна при запуске игры, а не при открытии книги.

## Ключи перевода

Для книги с префиксом `guide.yourmod`:

| Ключ | Что это |
|---|---|
| ключ из `.title(...)` и `.subtitle(...)` | Название и подпись на обложке |
| `guide.yourmod.section.N.title` | Название раздела N (нумерация с нуля) |
| `guide.yourmod.section.N.desc` | Описание раздела на его странице |
| `guide.yourmod.<глава>.title` | Название главы |
| `guide.yourmod.<глава>.desc` | Короткая подпись под названием в списке, около 18 символов |
| `guide.yourmod.<глава>.text` | Текст главы с разметкой |

Общие надписи интерфейса («Назад», «Продолжить чтение», счётчики страниц, «Оглавление») уже есть в Folio на русском и английском под ключами `folio.*`.

## Разметка текста

Текст главы — обычная строка перевода, в которой строки разделены переводом строки, а начало строки задаёт её вид:

- `# ` в начале строки — заголовок с линией под ним.
- `- ` — пункт списка с маркером.
- `> ` — врезка-совет на цветной подложке.
- Пустая строка — отступ между абзацами.

Внутри строки работают три вставки:

- `**жирный**` — выделенный текст.
- `[[id_главы|текст]]` — кликабельная гиперссылка на другую главу этой же книги. После перехода кнопка «Назад» вернёт читателя.
- `{{item:modid:item_id}}` — иконка предмета в тексте; при наведении показывается его подсказка.

Пример значения в lang-файле (в JSON перевод строки пишется как `\n`):

```json
"guide.yourmod.welcome.text": "# Первые шаги\nНайдите {{item:yourmod:some_item}} и изучите [[tools|инструменты]].\n- Берите **с собой** запас\n- Не торопитесь\n> Совет: в темноте опаснее всего."
```

> [!WARNING] Символ процента
> Не используйте в текстах символ процента: Minecraft принимает его за формат перевода, и строка ломается.

Если ссылка указывает на главу, которой нет в книге, она просто не откроется, поэтому сверяйте id глав с `.chapter(...)`. Если предмета с таким id нет, вместо иконки рисуется обычная книга.
